# Python Concepts

A collection of Python programs created while learning and practicing core Python programming concepts.

## 📚 Topics Covered

* **Basics** — Loops, conditions, and basic programming logic
* **Data Structures** — Lists, matrices, sets, and tuples
* **Functions** — Lambda functions and `reduce()`
* **Recursion** — Recursive problem solving
* **File Handling** — Text files, CSV files, log processing, and record management
* **OOP** — Classes, objects, constructors, and methods
* **Modules** — Using Python's built-in `math`, `statistics`, `os`, and `pathlib` modules
